# Azure CDN from Microsoft (classic) - historical example

Azure CDN from Microsoft (classic) [no longer supports new profiles or domains](https://learn.microsoft.com/en-us/azure/cdn/cdn-overview) and retires on September 30, 2027. This example is retained for reference and excluded from automated policy plans and E2E deployment tests because it cannot create a new deployment.

Use the [Front Door default example](../default) for new deployments.
